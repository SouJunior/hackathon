# AGENTS.md

## Repository Overview

This is a **documentation-only** repository for the SouJunior Hackathon event (Sept 11-25). All content is in Brazilian Portuguese. There is no application code, build system, or tests.

## Structure

- `index.md` — Entry point with navigation table linking to all docs
- `Desafio - Site SouJunior.tech.md` — Main challenge description
- `Regulamento Oficial_ Hackathon SouJunior.md` — Rules and evaluation criteria
- `Briefing de Produto_ Novo soujunior.md` — Product requirements (PRD)
- `Times.md` — Team formation guidelines
- `Parceiros.md` — Partnership/sponsorship proposals
- `1. Cronograma Sugerido (15 Dias).md` — 15-day sprint schedule

## Conventions

- All files are markdown with Portuguese content
- File names use spaces and special characters (use quotes or URL-encoding in links)
- External links point to Google Docs (edit mode) — keep these intact
- `index.md` is the central navigation hub — update it when adding/removing docs

## When Editing

- Preserve Portuguese text and formatting
- Maintain existing link structure in `index.md`
- Keep markdown tables aligned as-is
