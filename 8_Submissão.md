# Submissão do Hackathon SouJunior

## Requisitos para Validação da Entrega

Para que sua equipe seja considerada na avaliação, **todos** os itens abaixo devem ser cumpridos:

---

### 1. Repositório Open Source no GitHub

- O código-fonte do projeto deve estar em um repositório **público** no GitHub.
- O repositório deve conter uma licença open source válida (ex: MIT, Apache 2.0, GPL).
- O README.md do repositório deve conter: descrição do projeto, stack utilizada, instruções de execução e nomes dos integrantes.

---

### 2. Vídeo de Apresentação (máximo 5 minutos)

- Grave um vídeo curto demonstrando o projeto funcionando.
- O vídeo deve mostrar: a interface do site, os principais recursos implementados e a experiência do usuário.
- Formatos aceitos: YouTube (link público) ou upload direto no formulário de submissão.
- **Não é necessário aparecerem no vídeo** — o foco é o projeto.

---

### 3. Prazo de Entrega

- Todas as entregas (repositório + vídeo) devem ser feitas até a **data final do hackathon**.
- **Nenhum commit pode ser feito no repositório após a data e hora de encerramento.** Commits posteriores serão desconsiderados na avaliação.
- A data e horário de corte serão informados oficialmente no grupo do WhatsApp.

---

### 4. Classificação e Apresentação ao Vivo

- As equipes serão avaliadas conforme os critérios do [Regulamento Oficial](3_Regulamento%20Oficial_%20Hackathon%20SouJunior.md).
- **Os 3 primeiros colocados** terão a oportunidade de apresentar seus projetos ao vivo em uma **live oficial da SouJunior**.
- A live servirá como vitrine para a comunidade e para potenciais parceiros e patrocinadores.

---

## Checklist de Submissão

Antes de enviar, confira:

- [ ] Repositório público no GitHub com licença open source
- [ ] README.md completo com instruções de execução
- [ ] Vídeo de apresentação (máximo 5 minutos) gravado e link disponível
- [ ] Time devidamente cadastrado no [Google Form](https://forms.google.com/SEU_FORM_AQUI)
- [ ] Todos os integrantes são doadores no [Apoia.se](https://apoia.se/soujunior)

---

*Dúvidas? Entre no grupo do WhatsApp e fale com a organização.*
